# Momentum 功能概览

Momentum 是一款基于 CTDP（链式时间延迟协议）理论的专注力与自控力训练应用。

## 核心理念

### CTDP 理论基础

- **神圣座位原则**：特定触发器启动任务（如"戴上降噪耳机"）
- **先例原则**：失败的行动要么打断链条，要么成为永久例外
- **线性时间延迟原则**：带辅助链的调度系统

## 详细功能说明

### 1. 任务链系统 (Chains)

**核心功能**：

- 创建带触发条件和时长的任务链
- 单链与任务组两种结构；分类用自定义标签（名称 + 颜色，可多选，云端同步），旧的 6 种兵种类型迁移为默认标签，见 [链条标签](modules/CHAIN_TAGS.md)
- 连续完成次数追踪（当前连击、辅助连击、总完成/失败次数）
- 支持父子关系（层级链条）
- 无时长任务（手动完成）

**用户操作**：

- 创建新链条
- 编辑链条属性
- 复制现有链条
- 查看链条详情和统计
- 删除链条（软删除到回收箱）

### 2. 会话管理系统 (Sessions)

**核心功能**：

- 带辅助信号的预约会话
- 活动会话追踪（暂停/恢复）
- 无时长任务的正向计时器
- 会话完成历史
- 与赌注和宠物系统集成

**用户操作**：

- 预约任务（设置辅助信号）
- 开始/暂停/恢复任务
- 完成或中断任务
- 查看任务完成历史

### 3. 任务组系统 (Groups)

**核心功能**：

- 层级任务组，包含子单元
- 时间限制执行（小时）
- 顺序任务执行，自动推进
- 每任务重复次数
- 导入单元（复制或移动模式）

**用户操作**：

- 创建任务组
- 导入单元到组
- 设置时间限制和重复次数
- 顺序执行组
- 重新排序组内任务

### 4. RSIP 系统 (递归稳态迭代协议)

**核心功能**：

- 两种模式：自由模式（每日无限规则）和严格模式（每日最多1条）
- 层级规则树结构
- 稳定阶段：E0（新建）→ E1（稳定，7天）→ E2（内化，21天）
- 执行追踪和违规记录
- 违规时栈删除（删除节点及所有后代）
- 国策组与容错机制
- 强化等级与被动国策标记
- 轮次历史记录（崩溃原因追溯）
- 国策库（归档与恢复已验证国策）
- 分析与推荐引擎（KPI、趋势、风险识别、改进建议）
- RSIP-任务流程双向联动（事件驱动自动化协同）

**用户操作**：

- 添加新规则/政策
- 标记规则为已执行或违规
- 查看带阶段指示器的规则树
- 追踪执行历史
- 切换自由/严格模式
- 查看轮次历史和崩溃原因
- 从国策库恢复已归档国策
- 查看 Insights 面板（KPI、趋势、推荐）
- 配置 RSIP-任务联动（在 RSIP 主界面或任务编辑器内）

### 5. 例外规则系统 (Exception Rules)

**核心功能**：

- 两种规则类型：仅暂停、仅提前完成
- 全局和链条特定范围
- 使用追踪和统计
- 暂停选项：15分钟、30分钟、60分钟或无限制
- 自动恢复功能

**用户操作**：

- 创建暂停/提前完成规则
- 在任务执行期间应用规则
- 查看规则使用统计
- 归档/删除规则

### 6. 赌注系统 (Betting)

**核心功能**：

- 1:1 赔率（赢 = 2倍回报）
- 每会话单次下注
- 每日下注限额和单次最大下注
- 下注历史追踪
- 胜率统计

**用户操作**：

- 开启/关闭赌博模式
- 任务开始前下注
- 查看下注历史
- 检查当前积分和统计
- 设置每日限额

### 7. 电子宠物系统 (Pet)

**核心功能**：

- 宠物属性：饥饿、快乐、健康（0-100）
- 6 个进化阶段：蛋 → 婴儿 → 儿童 → 青少年 → 成年 → 老年
- 等级系统（1-100），指数级经验需求
- 基于属性的心情计算
- 属性随时间衰减
- 任务完成奖励

**用户操作**：

- 创建/领养宠物
- 喂养宠物
- 查看宠物状态和心情
- 追踪宠物进化
- 移动宠物小部件

### 8. 每日签到系统 (Daily Checkin)

**核心功能**：

- 每日签到获取积分奖励
- 连续签到追踪（当前和最长）
- 签到历史
- 今日签到状态

**用户操作**：

- 每日签到
- 查看当前积分
- 查看连续签到信息

### 9. 回收箱系统 (Recycle Bin)

**核心功能**：

- 带时间戳的软删除
- 恢复已删除链条
- 永久删除选项

**用户操作**：

- 查看已删除链条
- 恢复链条
- 永久删除链条

### 10. 导入导出系统 (Import/Export)

**核心功能**：

- 导出所有数据（链条、RSIP节点、设置）
- 从 JSON 导入数据
- 冲突解决
- 批量操作

**用户操作**：

- 导出项目数据
- 从文件导入数据
- 备份和恢复

### 11. 统计与回顾 (Statistics)

**核心功能**：

- 链条详情页的打卡热力图：最近 26 周每天的完成次数，含活跃天数与最长连续天数
- 专注时段：按完成时的本地小时统计，找出最常完成的时间段
- 连击走势：按完成历史计算每次记录后的连击数，失败归零
- 主页的本周回顾：完成次数、专注时长、成功率、活跃天数与上周对比，每天的完成柱状图，完成最多的链条

图表都支持悬停和键盘方向键查看明细，并为读屏软件提供文字说明。统计只读取完成历史，
任务组本身的记录不计入周回顾，避免与其单元重复。

### 12. 每日提醒 (Daily Reminders)

**核心功能**：

- 在链条详情页为某条链设置每天的提醒时间，提醒内容包含神圣座位
- 只保存在本设备（`momentum_daily_reminders`），不会同步，避免多台设备同时提醒
- 桌面端由 Rust 后台线程按本地时间调度，窗口隐藏时也会提醒；同一天只提醒一次，晚到 5 分钟内仍会补发
- 网页版只在页面打开时提醒；移动端暂不支持
- 需要先在设置中开启系统通知
